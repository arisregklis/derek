Frequently Asked Questions

Everything readers ask about formats, delivery, and how to open the files on different devices.

Each book is delivered as both a PDF and an EPUB, so you can read on virtually any device — phone, tablet, e-reader, or computer.

After checkout, you'll receive a confirmation email from Lemon Squeezy with a secure download link. The link gives you access to both the PDF and EPUB versions of your purchase.

For iOS Devices

Opening a PDF File

  1. Locate the file: after the download is complete, tap on the download icon (a downward arrow) in Safari, or go to the ‘Files’ app.
  2. Open the PDF:
    • In Safari, tap on the file name from the download list to open it.
    • In the ‘Files’ app, navigate to the location of the downloaded file (typically in ‘Downloads’ or ‘iCloud Drive’). Tap on the PDF file to open it.
  3. View and manage the PDF:
    • You can view the PDF directly in Safari or the Files app.
    • To annotate or manage the PDF, tap on the ‘Share’ icon (a box with an upward arrow) and select ‘Copy to Books’ to open it in the Apple Books app, which provides more features like annotation and organization.

Opening an EPUB File

  1. Locate the file: after the download is complete, tap on the download icon in Safari, or go to the ‘Files’ app.
  2. Open the EPUB:
    • In Safari, tap on the file name from the download list to open it.
    • In the ‘Files’ app, navigate to the location of the downloaded file (typically in ‘Downloads’ or ‘iCloud Drive’). Tap on the EPUB file.
  3. View and manage the EPUB:
    • Tap on the ‘Share’ icon and select ‘Copy to Books’ to open it in the Apple Books app.

For Android Devices

Opening a PDF File

  1. Locate the file: after the download is complete, swipe down from the top of the screen to access the notification shade and tap on the download notification, or use a file manager app to locate the file in the ‘Downloads’ folder.
  2. Open the PDF:
    • Tap on the file name from the download list or in the file manager app to open it.
  3. View and manage the PDF:
    • You can view the PDF using the built-in PDF viewer.
    • For more features, you can open it with Google Drive PDF Viewer, Adobe Acrobat Reader, or any other preferred PDF reader app by selecting the appropriate app when prompted.

Opening an EPUB File

  1. Locate the file: after the download is complete, swipe down from the top of the screen to access the notification shade and tap on the download notification, or use a file manager app to locate the file in the ‘Downloads’ folder.
  2. Open the EPUB:
    • To open an EPUB file, you need an eBook reader app like Google Play Books, Aldiko, or any other EPUB-compatible app. If you haven’t installed any, download one from the Google Play Store.
    • Once you have an eBook reader app installed, tap on the EPUB file, and select the eBook reader app to open it.
  3. View and manage the EPUB:
    • You can now read and manage your EPUB file within the eBook reader app.

By following these steps, you should be able to open and read your downloaded EPUB and PDF files on both iOS and Android devices.
